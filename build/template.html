Free trial

Run The Whole Platform, Free

Not just one accelerator — the Fuuz platform itself, on your own machine. Fuuz In-House is a slimmed-down deployment that runs entirely in Docker, so you can try Fuuz for yourself before it touches any infrastructure of yours.

One container, the whole platform

The launcher pulls and runs roughly 32 containers — three RabbitMQ brokers, a MongoDB replica set, Redis, object storage, an nginx reverse proxy, and the Fuuz platform services themselves — then hands you a local web UI to configure and start it.

What it needs

Docker on 64-bit x86 (amd64), 12 GB memory minimum (16 GB recommended), 4+ CPUs, ports 80/443 free, and outbound Docker Hub access for the initial pull. A license key is required to start it.

Getting a license

Request a trial license through the official form, or use the key you were supplied with if you're already a subscription customer. The license key is what unlocks the launcher's local UI at localhost:9000.
