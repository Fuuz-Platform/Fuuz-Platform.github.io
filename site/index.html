Accelerators.

Pre-built packages, applications and runnable simulators for the Fuuz platform. Each one is a public repository you can read before you install anything — and some of them you can run on a laptop without a Fuuz tenant at all.

Run it now

Accelerators that stand up on their own machine, with documentation published here.

ACE Docker Simulator

An OPC UA plant, a MongoDB time-series historian and a Fuuz-shaped GraphQL API, in one docker compose up. 88 live tags, real quality codes, injected faults.

Device Gateway repo

One-command Docker deployment for the Fuuz Device Gateway — the component that connects plant equipment to the platform.
